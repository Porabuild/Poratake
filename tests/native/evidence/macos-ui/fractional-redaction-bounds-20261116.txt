A generated 12x12 black image contained one white pixel at (9,9). The redaction
covered x=1.5, y=1.5, width=8, height=8. Before the fix the GPUI pixelation
test left the corner pixel at 255 because its source region stopped before that
pixel. After the fix GPUI's generated pixelation and blur tests both changed
the corner. Region tests also covered negative coordinates, the right and bottom
canvas edges, 2x scale, and zero width or height.

A hidden offscreen Electron window ran the production drawing renderer on the
same generated image after the fix. Pixelation produced RGBA [0,0,0,255] at the
corner; blur produced [241,241,241,255]. For each, the outside pixel at (10,9)
remained [0,0,0,255]. This run used a generated canvas and a temporary Electron
profile; it did not capture a screen or use the existing editor.

The GPUI annotation tests, screenshot-export tests and screenshot-preview
tests passed on macOS. Vitest covered Electron's source and clip bounds at 1x
and 2x, negative coordinates, canvas edges and empty selections. The generated
edited-video export test uses fractional pixelation and blur coordinates,
