The Electron samples were generated by bundling the repository's production
renderDrawings implementation into a local, hidden Electron 43.4.0 window:

bun build tests/native/evidence/macos-ui/video-blur-reference.ts --target browser --outfile /tmp/poratake-video-blur-reference.js
env -u ELECTRON_RUN_AS_NODE node_modules/.bin/electron tests/native/evidence/macos-ui/video-blur-reference.cjs > tests/native/evidence/macos-ui/video-blur-electron-20261116.json

The inputs are synthetic, no screen capture or devices. The output is reproducible
byte-for-byte on this machine. At unit scale, a blur covering a uniform half-alpha
canvas corner produced [65,128,192,145] in Electron and [64,128,191,192] in the
previous GPUI video path. GPUI now uses transparent sampling outside the source;
the retained Rust tests check the full canvas, left and right clipped cases, and
opaque stripes at both edges against the Electron samples.

A separate comparison found that at 0.5x transform Electron produced red value
173 at the left edge of a clipped opaque stripe. GPUI with its existing
composition-proportional blur size produced 247. Changing GPUI's scale rule to
match that sample would make blur size vary between its scaled editor preview and
an original-size export, so the GPUI scale rule was retained. Electron's scaled
blur behavior remains a parity difference; the reference JSON also includes 0.73x,
1.5x and 2x samples.
