macOS rounded-blackout comparison, 2026-11-16

The pinned Electron 43.4.0 runtime and Chromium 150.0.7871.224 rendered a hidden
window with an isolated temporary user-data directory. The Electron probe uses
the same rectangle and blackout SVG attributes and canvas blackout operation as
the renderer, on a synthetic opaque background. It does not launch Poratake or
access screen capture, audio, camera, or the user's editor. Three scales and
three equal x/y offsets are sampled for each annotation order. Each result is a
4x4 RGBA patch at the blackout's upper-left corner.

The GPUI test fixture renders the equivalent inputs using the production
compose function. The included JSON files contain the two sets of pixels.
blackout-order-compare.py checks matching geometry and compares every channel.
With the rectangle below the blackout, 62 of 576 channels differ by over two,
with a maximum difference of 34. With the rectangle above it, all 576 channels
match. In the integer-origin 1x case the respective corner values are 191 and
158 for GPUI and Electron. An older GPUI test expected 169 for the corner;
its source has not been established.

blackout-corner-electron-43.json contains the pinned Electron rendering of the
separate simple SVG used by the earlier Chrome probe. blackout-corner-compare.py
compares it to the retained Tiny Skia outputs: 32 of 144 red samples differ by
over two, maximum 34. The earlier 4x supersampled scratch output has 31 samples
over two, maximum 18. Neither probe demonstrates a complete editor workflow,
physical DPI behavior or real captured content; supersampling was not adopted.

To repeat the Electron probes, run blackout-corner-electron.cjs with an existing
Electron 43.4.0 executable and ELECTRON_RUN_AS_NODE unset. Its optional argument
blackout-order-electron.html selects the layered composition; without it the
simple SVG is used. To repeat the GPUI probe, temporarily include
blackout-order-gpui.rs inside editor/export.rs's test module, run the
blackout_order_gpui_probe Rust test with --nocapture, and remove the include.

The follow-up actual-exporter fixture invokes exportAnnotationToSvg from the
renderer source for each rectangle and blackout. Its first version omitted the
initial rectangular blackout pass; after adding that pass, all 18 sampled
objects still matched the earlier reproduction exactly because the shape covered
those samples. The fixture also records a standalone fractional blackout boundary.
It does not open the complete editor or access capture or media devices. To repeat
with the installed local dependencies:

node_modules/.bin/vite --config scripts/parity/vite.renderer.mts --host 127.0.0.1
env -u ELECTRON_RUN_AS_NODE node_modules/.bin/electron scripts/parity/blackout-exporter-probe.cjs

The Electron process uses a temporary user-data directory and a hidden offscreen
window. Stop the Vite server when finished. Output is JSON with Electron version,
GPU status and sample pixels; no exact match is assumed across GPU backends.

The probe also renders the actual Electron RedactOverlay component over a
generated white image, then composites its canvas over white for sampling. At
the offscreen window's 1x device pixel ratio, the tested far-edge preview pixels
and the corresponding export pixels were black, while sampled pixels just
outside were white. blackout-preview-electron-20261116.json records those
samples. The component regression additionally checks simulated 2x canvas
dimensions, reversed and clipped selections, and offsets. The offscreen probe
does not establish physical 2x output or compare all pixels at unequal preview
and export scales.

The unequal-scale case uses a generated 200 x 160 white source displayed at
100 x 80, the actual Electron preview canvas and live SVG annotation components,
and a reconstructed native-scale export using the actual blackout and SVG
export helpers. It removes the SVG's transparent selection guide before
compositing the preview. Canvas draws the 200 x 160 export down to 100 x 80
with high-quality smoothing. Electron 43.4.0 reported 52 of 8,000 pixels more
than two channel levels apart, maximum 191. Four mid-edge pixels were black in
the preview and 128/255 gray in the downscaled export. All 676 pixels touched
by the selection were opaque black in the native-resolution export. The
blackout-scale-comparison-20261116.json and paired PNGs retain these results.
This does not render the full editor or its interaction guides and does not
establish physical display behavior.
