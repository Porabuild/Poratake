macOS GPUI music paths, temporary project tests

Before the fix, a scratch track filename containing ../../ caused the remove
path to delete a file outside the project's music folder. A separate scratch
import followed a dangling destination symlink and created a file outside the
project. Both tests failed before the fix and passed afterward.

The updated path checks reject parent and absolute track filenames, a symlinked
music folder, and a symlinked music file. Imports create their destination
exclusively and choose another name if a file or symlink already occupies it.
Two simultaneous generated WAV imports with the same filename both completed
with distinct files and their original bytes. The music, audio-track and
generated import/replacement tests passed on this Mac.

Directory validation still uses path-based filesystem checks; these tests do
not establish containment if another process replaces a directory concurrently.
All files used by the checks were in temporary directories.
