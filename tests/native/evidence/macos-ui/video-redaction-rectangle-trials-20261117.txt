macOS generated video crop experiments, 2026-11-17
Base: 22b4d40a

The saved 512-case diagnostic at this base reports 12 channels differing by
more than one level in 1,137,319 effect-area pixels; the largest difference is
three. The existing full-versus-crop rectangle source diagnostic reports two
channel differences, maximum 28, at its crop boundary.

A trial using the existing screenshot path anchor in the video crop left the
matrix unchanged: 12 channels, maximum three. It was removed.

A separate trial increased each output-target source crop's one-pixel margin to
five pixels. The matrix still failed: five channels differed by more than one
level, maximum two. The trial patch is video-redaction-margin-trial-20261117.patch.
This finite margin does not establish that arbitrary rectangle geometry is
rasterized consistently and was removed.

Another trial included the full clipped bounding box of a rectangle when its
outline intersected the source crop, included half the stroke plus one pixel,
kept crops wholly inside the rectangle's interior separate, and merged the
resulting intersecting groups. The matrix still failed with seven channels,
maximum two. For a generated 3840x2160 frame fitted to 960x540, a 320x240
pixelation intersecting a 4px full-frame rectangle caused the source crop to
expand across the frame. Six timed iterations after warmup gave a local upper
median of 40.82 ms. Disabling rectangle-bound expansion with the same test scene
in a subsequent run gave 5.69 ms. These short optimized test-profile runs omit
decode, GPU upload and playback; scheduling and run order were not controlled.
The full-bounds approach was removed because it can turn a small crop into a
full-frame render. It is not a general solution.

The benchmark setup is retained in
video-redaction-rectangle-timing-diagnostic-20261117.patch. Apply it to a
clean checkout at 22b4d40a and run:

cargo test --offline --locked --manifest-path src/main/Cargo.toml -p poratake-gpui rectangle_crop_composition_timing_probe -- --ignored --nocapture

The source crop margin trial can be combined with the existing rectangle
512-case diagnostic after restoring that matrix from bb19e02a, as described in
video-redaction-rectangle-crop-20261117.txt. Both tests use generated pixels;
no physical display, capture, editor window or decoded export was exercised.
