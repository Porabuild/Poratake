display and an authorized screen-only daemon. A generated moving

START_FAILED reply on the first recording attempt and held the real

keyboard tracking were disabled for the live retry.

retry runs completed real screen-only recordings and opened the video
preview. Each file contained a single video stream with at least
four frames. The first failed project did not remain. A separate
dark run cancelled the pre-recording toolbar during the hold and
saw the toolbar close and the output directory stay empty.

These are individual app-local response observations. They do not
measure input delivery from a physical device or compositor scan-out.
